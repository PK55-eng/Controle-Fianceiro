# Documento de Visão — FinanSee
O FinanSee é uma aplicação web de gestão financeira pessoal criada para centralizar receitas e despesas e facilitar a compreensão da situação financeira. O problema abordado é a dificuldade de acompanhar movimentações dispersas em anotações ou planilhas e transformar registros em informações úteis.

A aplicação organiza transações por conta e categoria e apresenta saldo, receitas, despesas e gráficos. O projeto aplica Engenharia de Software, API REST, banco relacional, Docker, versionamento e desenvolvimento assistido por IA.
